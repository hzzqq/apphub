期库镜怎么看「强相关」：
库存与期货价格通常不是简单正相关。常见规律：库存下降往往支撑价格（利多），库存累积往往压制价格（利空），即价格与库存多呈负相关。本工具用皮尔逊相关系数 r 定量刻画：
· |r|≥0.6 强相关 · 0.3≤|r|<0.6 中等 · |r|<0.3 弱相关
⚠️ 关于「库存数据到底代表什么」（你问的关键问题）：
每个交易所公布的库存 = 该交易所自家指定交割仓库里的显性库存，不是该品种全球总库存。
· 例如选「沪铜」，看到的是 SHFE 上海/广东/江苏/浙江/天津等地指定交割库的库存；选「LME铜」是 LME 全球 37 地 700+ 仓库的库存；选「COMEX铜」是北美交割库库存——三者各自独立统计，互相不是扩容合并。
· 同一品种（如铜）全球至少有 SHFE + LME + COMEX 三套并行库存，且会相互套利搬运（此消彼长），所以单独看某一家意义有限，应看增量整体变化。
· 即便三家加起来也只是「全球交易所显性库存」，还有大量看不见的隐性库存：保税区库存、冶炼厂产品库存、贸易商存货、国储库存、融资铜（锁定在套利里的影子库存）。
· 因此本工具提供「全球合计」视图（SHFE+LME+COMEX 相加），比单家更接近真实全局，但仍是显性部分。
· 新增多库存指标切换：总库存、可流通库存、注册仓单、保税区库存。与价格相关的不一定是「总库存」，可流通库存/注册仓单往往反应更快、相关性更强；工具默认「自动最相关」帮你选出当前品种、当前区间里与价格相关度最高的指标。
真实数据从哪来（联网查证后内置为接口钩子，模仿 StockSignal 数据源）：
· 行情源：模仿 StockSignal —— 默认新浪实时行情 hq.sinajs.cn/list=（需 Referer: finance.sina.com.cn，GBK 解码）+ akshare 兜底（多源 fallback）。
· 上期所 SHFE 每周五库存周报：akshare.futures_inventory_shfe(date="YYYYMMDD")；大商所/郑商所/能源中心：futures_inventory_dce/czce/ine。
· 外盘 LME：官方 XML Feed 需授权；公开镜像 westmetall.com 每日发布 LME 铜铝锌铅镍锡库存总量，免授权可抓。
· 外盘 COMEX：CME 每日发布金银铜注册/交割库存报告（官网公开）。
为什么默认是真实数据：期库镜默认走真实数据——优先后端（本地缓存/akshare 真抓），无后端时回退内置真实样本（纸浆 SP 已收录 2026 公开实盘点）。纯前端单文件受 CORS 限制无法直接抓外网，故需后端代理；配置「真实数据接口」填入统一后端根地址（如 http://127.0.0.1:8787）即显示实时真实库存与行情。

真实数据接口配置

填入一个返回 JSON 的后端地址，本工具会用 ?symbol=品种代码&mode=库存口径 调用它。 期望返回格式：[{ "date":"2026-08-01","close":68900,"inventory":152000 }, ...] （inventory 单位：吨；缺失字段用 null）。

行情源模仿 StockSignal：行情走新浪 hq.sinajs.cn + akshare 兜底；库存走 akshare 各交易所接口或 westmetall/CME。
填入统一后端根地址即可，例如本地启动的 http://127.0.0.1:8787。后端需提供 /api/futures、/api/corr_top、/api/search。
真实数据源：akshare 抓行情+多口径库存，模仿 StockSignal 多源 fallback。后端默认真实数据（本地缓存优先→akshare 真抓→离线样本兜底）；沙箱禁网时回退离线样本。

期库镜 · 数据说明

① 数据口径
库存为各交易所「显性仓单库存」，单位吨，取自东方财富 akshare 公开接口；原油(SC)无交易所仓单口径，采用美国 EIA 周度原油库存变动（百万桶）作为真实库存信号。

② 数据真实性
除界面明确标注「合成演示」外，均为真实抓取 / 内置公开实盘样本；合成数据仅为无后端、无样本时的兜底，且会显式警告，绝不静默冒充真实行情。

③ 如何刷新
启动本地后端（端口 8787）后自动读取真实缓存；或点「🔄 刷新数据」从东方财富重新抓取；全品种概览点「🔄 刷新概览」。

④ 局限性
库存非每日发布（按交易所固定工作日更新）；EIA 原油为周度快照，当前内置数据截至 2025-09-05，非实时；如需原油实时，可接入 EIA 官方 API key。
