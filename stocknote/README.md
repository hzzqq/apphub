# 股事贴 StockNote · 个股事件速记卡

从 StockSignal 事件追踪模块抽离出来的**独立零依赖微型 App**。
记录"某只股票在某天发生了什么事（利好 / 利空 / 备忘）"，纯本地保存，方便复盘。

## 它解决什么
大平台功能多但启动成本高。这个工具只做一件事：让你**30 秒内记下一笔股票事件**，
下次打开浏览器还在，按股票分组一眼看清某只票的全部催化/风险。

## 怎么用
1. 双击 `index.html` 直接在浏览器打开（无需安装、无需联网、无需构建）。
2. 填代码 / 名称 / 日期 / 类型 / 内容 → 点「保存速记卡」。
3. 顶部搜索框按代码或名称实时过滤；点「按股票分组」切换视图。
4. 卡片可「编辑」「删除」（删除会确认）。
5. 「导出 JSON」把全部记录下载成文件；「导入 JSON」恢复（方便迁移或备份）。

## 数据存在哪
全部存在浏览器 **localStorage**（键名 `stocknote.records.v1`）。
- 优点：零后端、隐私本地化、换电脑不丢（只要导出 JSON 带走）。
- 注意：清理浏览器数据 / 换浏览器会丢，重要数据记得定期「导出 JSON」。

## 配色约定（A 股语义）
- 利好 = 红 `#ff4d4f`
- 利空 = 绿 `#00d486`
- 备忘 = 灰 `#8a8a9a`
深色主题：底色 `#0f0f23`，卡片 `#1a1a2e`，紫蓝渐变 `#667eea→#764ba2`。

## 如何二次开发
单文件，CSS + JS 全内联，结构清晰：
- `state.records` 是数据数组，每条 `{id, code, name, date, type, content, createdAt}`。
- `persist()` 写入 localStorage；`render()` 重绘列表；`renderStats()` 重绘统计。
- 想加功能（如导出 CSV、按类型筛选、接入实时行情），在对应函数里加即可。
- 想做成收费原型：把 localStorage 换成后端 API，前端逻辑基本可复用。
