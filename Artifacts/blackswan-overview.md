# 黑天鹅预警 App「Black Swan Radar」交付总结

## 做了什么
按老板要求，开发了独立的「黑天鹅预警」微型 App，覆盖**系统性宏观利空**与**个股风险**两个维度，所有事件数据均经联网查证（证券时报/新浪财经/中国新闻网等公开资料），不靠记忆硬编。

## 交付文件
- `E:\project\app\blackswan\index.html` — 主交付，零依赖单文件，双击即开
- `E:\project\app\backend\app.py` — 配套后端新增 `/api/blackswan` 端点（已追加到既有 Flask 服务）

## 核心功能
1. **宏观黑天鹅时间轴**（内置已考证事件）：
   - 2007–08 次贷危机：6124→1664，最大跌幅 72.8%
   - 2015 杠杆牛崩塌/股灾：5178→2850，8-24 单日 2187 只跌停
   - 2018 特朗普加税（贸易战）：单日 -3.39%，全年最低 2449
   - 2020 新冠疫情：春节后首日 -7.72%，超 3000 股跌停
   - 2022 俄乌冲突 + 美联储加息：3 月沪指 -6.07%、创业板年内 -19.96%
   - 2008 印花税下调（反向政策信号案例）
2. **个股风险扫描**：业绩雷/财务造假（康美药业 887 亿造假、乐视退市）、监管异动（问询函/停牌核查）、减持/立案示例。
3. **预警等级仪表盘**：按可见事件等级加权出 0–100 分，分 🔴高风险/🟡中度/🟢平稳 三档研判。
4. **筛选 + 自定义**：按「宏观/个股/我的记录」分类、按等级过滤、手动录入自己的事件（localStorage 持久化）、可视化时间轴。
5. **数据源配置**：填后端 `http://127.0.0.1:8787` 即调 `/api/blackswan` 拉升真实事件库与个股risk样本。

## 关键决策
- 纯前端单文件无法真联网，故内置事件均为**公开历史查证数据**；后端离线返回样本，真网可扩展 akshare 公告/财报雷实时监控。
- 股票涨跌配色遵循 A股惯例（涨→红、跌→绿），深色主题 #0f0f23。

## 校验
- 前端 JS 语法 + 深色/红绿配色 + 事件库存在 + 仪表盘 SVG + 后端接口全 PASS
- 后端 `/api/blackswan` 返回 6 事件 + 4 个股，端点已注册
