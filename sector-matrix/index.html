怎么读：每行是一个品种（行名后蓝标签 = 它自身所属板块），每列是一个板块；格子数字 = 该品种与「该板块等权指数」的日收益平均相关（原始相关）。列已按板块分组（列头顶部色条同色=同板块），一眼看出板块聚类。 把同板块多个品种等权合成一个板块指数再算相关，就能把联动拆成两类：
· 板块内共振（蓝框）——品种与自己所在板块的同步程度。数值高 = 该板块行情整体性强、品种被板块带着走；数值低 = 板块内部分化，该品种有独立行情（α 更强）。
· 跨板块传导（无框）——品种受其他板块行情的溢出影响，通常是产业链上下游或共同宏观驱动（如地产链、能源成本、美元流动性）。
鼠标悬停格子看偏相关（已剔除全品种等权市场因子，偏相关仍高 = 真实产业/宏观传导，而非大盘带动）；悬停品种名可直接对比「板块内共振 vs 最强跨板块」。点「下钻 ↗」打开该品种完整联动报告。 交互：点击板块列头可按该板块共振强度给品种排序（再点切换升/降序，▼=最强在前）；点击品种名可高亮该行做对比；顶部板块内共振 / 跨板块传导切换可只看一类联动；导出 CSV把当前矩阵下载为表格。
